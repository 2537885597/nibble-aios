# Nibble 桌面宠物 🐰

一只用「扭扭棒 + 毛线手工玩偶」形象打造的可互动 AI 桌面宠物。基于 Electron 实现，
开箱即用（无需任何 API Key 也能互动），配置好 AI 服务后还能进行自由聊天、语音交互、
主动搭话、记住你们聊过的事情。

![Nibble icon](assets/icon.png)

## ✨ 已实现的功能

**桌宠本体**
- 直接使用手工玩偶原图渲染（`assets/character.png`），已抠除黑色背景并保留透明通道，
  更贴近真实扭扭棒 + 毛线人偶形象，同时保留 CSS 状态动画。
- 待机呼吸、随机眨眼（位图模式下保留状态逻辑，不再依赖 SVG 元素）、摸摸头的挤压反弹、
  说话时的身体点头、深夜/久未互动后自动进入睡觉状态（会飘 Zzz）。
- **多种待机动作**：会**侧过身来来回走动**（前后小幅踏步 + 前倾，用收窄身形暗示侧面）、
   **原地跳跃**、**坐下休息**，三种动作随机切换；自由走动时也会以侧面走路的姿态在桌面上溜达。
   （目前只有正面位图，侧面是用 CSS 形变近似表现的，后续可换精灵帧/侧身素材做到真正侧影。）
- 鼠标靠近角色时会出现一个跟随鼠标的小手手提示，告诉你"这里可以摸"；
  单击是摸摸头互动，按住拖动是移动位置（手动实现的拖拽逻辑，避免了 Electron 拖拽区域
  偶尔"点了没反应"的问题），右键弹出功能菜单，双击直接打开聊天窗口。
- 会在桌面上自己随机小范围走动/跳动（可在设置中关闭）。
- 透明背景、无边框、始终置顶，退出后位置会被记住。

**AI 互动**
- 点击/摸头会有即时的可爱反应（内置文案，无需联网）。
- 打开聊天窗口可以和它自由对话，接入任意 **OpenAI 兼容接口**（DeepSeek、Moonshot、
  通义千问、OpenAI 官方等）即可拥有真正的智能回复；不配置也能用内置的关键词式罐头回复兜底。
- 会按时间段（早/中/下午/傍晚/深夜）主动弹出气泡搭话，提醒喝水、吃饭、休息、睡觉。
- 好感度系统：摸头、聊天都会增加好感度，好感度分「陌生 / 熟悉 / 亲密 / 挚友」四个阶段，
  会影响它说话的亲密程度（同时写入系统提示词，让大模型的回复语气也随之变化）。
- 简单的长期记忆：每天结束时（如果配置了 API Key）会自动把当天的对话总结成一句话存档，
  之后聊天时会作为「值得记住的往事」提供给大模型，让它显得更有记忆、更有连续性。

**语音交互（ASR + TTS）**
- **语音播报（TTS）**：Nibble 说的每一句话（气泡内容、聊天回复、主动搭话）都可以自动
  读出来，默认使用微软 **Edge TTS**（云端、中文音色自然、免费），可在设置里选择音色并调整
  语速/音调/音量；也支持切回系统自带的 Web Speech 作为离线回退。
  聊天窗口里每条回复都有单独的"朗读"按钮可以重听。
- **语音识别（ASR）**：聊天窗口输入框旁有一个麦克风按钮，点一下开始录音、再点一下结束
  （或最长 15 秒自动结束），录音会被发送到 Whisper 兼容的转写接口，识别成文字后自动发送。
  这部分默认复用「AI 服务」里配置的地址和 Key，也可以在设置里单独指定一个不同的语音识别服务商。

**可配置项（设置窗口）**
- 昵称、窗口大小缩放、开机自启动、窗口置顶
- 自由走动开关、主动搭话开关、安静时段（不打扰时间段）、互动音效开关
- 语音播报开关 / 语速 / 发音人（可试听）、语音识别服务配置
- API 地址 / API Key / 模型名称 / 人设系统提示词，支持一键测试连接
- 好感度重置、聊天记录清空

## 🖥️ 快速开始

```bash
npm install     # 安装依赖（会自动生成 assets/icon.png）
npm start       # 启动桌宠
```

> 首次 `npm install` 时会下载 Electron 的可执行文件（体积较大）。如果你在国内网络环境下载很慢，
> 可以设置国内镜像后再安装：
>
> ```bash
> # Windows (PowerShell)
> $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"; npm install
>
> # macOS / Linux
> ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
> ```

启动后，Nibble 会出现在屏幕右下角，同时系统托盘会出现一个图标：
- **左键单击托盘图标**：显示/隐藏桌宠
- **右键托盘图标 / 右键桌宠本体**：打开功能菜单（聊天、设置、置顶、走动开关、退出等）
- **双击桌宠**：直接打开聊天窗口
- **单击桌宠**：摸摸头，触发好感互动
- **按住拖动**：移动到桌面任意位置

## 🤖 配置 AI 服务（可选，但强烈建议）

打开「设置」，在 **AI 服务** 区域填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| API 地址 | OpenAI 兼容的 base URL | `https://api.deepseek.com/v1` |
| API Key | 服务商提供的密钥 | `sk-xxxxxxxx` |
| 模型名称 | 服务商支持的模型 | `deepseek-chat` |
| 人设 / 系统提示词 | 定义它的性格与说话方式，支持 `{{petName}}` 占位符 | 已内置默认人设 |

填好后点击「测试连接」确认可用，再点击「保存设置」。不填也完全不影响使用，只是聊天回复
会退化成内置的关键词式简单回复。

## 🎙️ 配置语音识别（可选）

语音播报默认使用 Edge TTS，开箱即用。语音识别需要一个 **Whisper 兼容的转写接口**
（`/audio/transcriptions`），不是所有 OpenAI 兼容服务商都支持，纯聊天类接口
（例如部分 DeepSeek/Moonshot 套餐）可能没有该接口。推荐用 OpenAI 官方的 `whisper-1` 模型，
或 Groq / Faster Whisper 等兼容服务。

如果你的聊天服务商不支持，可以在设置的「语音」区域勾选「语音识别使用单独的服务地址」，
单独填一个支持转写的服务商信息。

首次点击麦克风按钮时，Windows 可能会弹出隐私权限相关提示——如果没有声音识别效果，
请检查系统设置里「麦克风」隐私权限是否允许桌面应用访问。

## 📁 项目结构

```
deskmate-nibble/
├── main.js                     # Electron 主进程：窗口管理、托盘、IPC、AI/ASR 调用、定时任务
├── preload.js                  # 预加载脚本，向渲染进程暴露安全的 window.api
├── scripts/
│   ├── generate-icons.js       # 纯 Node 实现的最小 PNG 编码器，生成应用图标
│   ├── process-character.py    # 把 assets/original-image..png 处理成透明背景 character.png
│   └── debug-screenshot.js     # 开发用：渲染桌宠窗口并截图到 debug-screenshot.png，
│                                 用于快速检查角色外观改动（electron scripts/debug-screenshot.js）
├── src/
│   ├── common/                 # 主进程使用的业务逻辑（不依赖 Electron API，便于测试/复用）
│   │   ├── store.js            # 本地 JSON 持久化（配置 / 记忆 / 好感度 / 窗口位置）
│   │   ├── llm.js              # OpenAI 兼容 /chat/completions 调用（原生 https，无三方依赖）
│   │   ├── asr.js              # Whisper 兼容 /audio/transcriptions 调用（手写 multipart 编码）
│   │   ├── edgeTts.js          # 微软 Edge TTS 封装（基于 msedge-tts）
│   │   ├── personality.js      # 默认人设 & 系统提示词拼装（含好感度阶段、长期记忆摘要）
│   │   └── idleLines.js        # 离线可用的罐头文案（摸头反应 / 主动搭话 / 兜底回复）
│   └── renderer/
│       ├── pet/                # 桌宠本体窗口（透明、无边框、置顶）
│       │   ├── index.html      # 桌宠渲染 HTML（使用 character.png 位图）
│       │   ├── pet.css         # 状态动画（待机/跳跃移动/反应/睡觉/说话）
│       │   └── pet.js          # 状态机、手动拖拽/点击判定、气泡、TTS 播报、与主进程的 IPC
│       ├── chat/               # 聊天窗口（含语音输入、逐条朗读）
│       └── settings/           # 设置窗口（含语音设置）
└── assets/
    ├── original-image..png     # 手工玩偶原图（可替换后重新生成 character.png）
    ├── character.png           # 处理后的桌宠形象（透明背景）
    └── icon.png                # 自动生成的应用图标
```

## 🎨 自定义角色外观

角色现在直接使用位图渲染（`assets/character.png`），源文件来自手工玩偶照片
`assets/original-image..png`。如果你想要换一张形象：

1. 替换 `assets/original-image..png` 为你自己的角色照片（最好主体与纯色背景对比明显）。
2. 运行 `python scripts/process-character.py`，脚本会自动抠除背景并生成新的
   `assets/character.png`。
3. 再运行 `electron scripts/debug-screenshot.js` 预览效果。

状态动画（呼吸、跳跃、说话点头等）在 `src/renderer/pet/pet.css` 中通过 `.state-*`
作用于 `#character-img`，你可以按需调整幅度和速度。

## 🗺️ 后续可以扩展的方向

当前版本使用「原图位图 + CSS 动画」方案，兼顾了形象还原度和开发成本；表现力上不如
逐帧动画或 Live2D 丰富。语音部分也是先接入了最基础可用的方案。如果想继续往下做，
可以按优先级推进：

1. **更丰富的美术表现**：把角色升级为精灵帧动画或接入 Live2D，制作更细腻的表情与动作，
   也可以补充侧面/背面素材，让移动方式从"跳跃"升级为真正的"走路"。
2. **屏幕感知**：定时截屏 + 视觉模型分析，让主动搭话更贴合你正在做的事情。
3. **更强的长期记忆**：引入向量数据库（如 ChromaDB）替换现在「每日摘要」的轻量方案。
4. **流式语音体验**：把 ASR 换成流式识别（说话时实时转文字），TTS 换成更自然的云端音色。
5. **工具调用**：让它能帮你查资料、设置提醒、操作浏览器等。
6. **打包分发**：引入 `electron-builder` 或 `electron-forge`，产出可分享的安装包。

## ⚠️ 已知限制

- 拖拽/点击的判定区域是桌宠窗口的矩形区域，而不是像素级别的角色轮廓（简化实现，
  日常使用不受影响）。
- 聊天调用大模型接口为非流式（一次性返回），暂未做打字机式的流式输出。
- 语音识别依赖服务商是否提供 Whisper 兼容的转写接口，并非所有 OpenAI 兼容服务商都支持。
- 语音播报默认走 Edge TTS，需要能够访问微软服务；离线环境可切回 Web Speech，
  此时音色取决于操作系统是否安装了中文语音包。
- 目前只在 Windows 环境下测试过；`skipTaskbar`、开机自启、麦克风权限等在 macOS / Linux 上
  的表现可能需要额外适配。
